Security note

The generated file stores the token in plain text — anyone holding the file can use its permissions. Prefer a fine-grained token limited to the one apps repository, and rotate it if you think it leaked.

For copies you hand to students, consider a read-only token (Contents: Read-only). Syncing and downloading still work — only publishing is blocked.

Quick guide

  1. Create a GitHub repository for the mini apps, e.g. yourname/school-apps.
  2. Create a fine-grained Personal Access Token with Contents: Read and write on that repository only.
  3. Fill in the form, click Test connection, then Build & download.
  4. Share the generated HTML file with your class — it opens fully configured.
