Mathematics Teacher Portfolio - GitHub Pages Package

FILES:
- index.html
- assets/images/ (55 exported image file/s)

HOW TO UPLOAD TO GITHUB PAGES:
1. Unzip this package on your computer.
2. Upload index.html and the assets folder to the root of your GitHub repository.
3. Do not upload only the ZIP file. GitHub Pages needs the unzipped files.
4. In GitHub, go to Settings > Pages and publish from the main branch/root folder.

EDITING LATER:
Use portfolio-builder.html and your portfolio-data-backup.json to edit your content, then export a new package.
